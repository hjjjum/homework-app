중1과 초5를 어떻게 나눴나
첫째(중1) — 젤리·구름 테마를 기본으로, 글꼴은 담백하게. 아기 같은 문구 대신 "남은 2개" 같은 사실 위주. 축하 문구도 짧게.
둘째(초5) — 마법 정원. 씨앗→새싹→봉오리→꽃으로 오늘 진행이 자라고, 말투도 다정하게.
테마는 언제든 바꿈 — 아이가 스스로 고르는 것 자체가 애착을 만듭니다. 화면 맨 아래 칩에서 즉시 전환.
진동만 — 체크할 때 15ms 짧은 진동, 완주할 때 두 번. 소리는 없어 도서관·수업 중에도 안전.
되돌리기 자유 — 다시 누르면 취소되고 링도 줄어듭니다. 잘못 눌러도 겁먹지 않게.
